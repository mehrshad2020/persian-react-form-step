## معرفی

این پروژه یک فرم چند مرحله‌ای (Multi-Step Form) با پشتیبانی کامل از راست به چپ (RTL) برای زبان فارسی است. پروژه با استفاده از React و TypeScript ساخته شده و از فونت وزیر برای نمایش متن فارسی استفاده می‌کند.

این فرم چند مرحله‌ای شامل 5 مرحله است:
1. **نام شما** - برای ورود نام و ایمیل
2. **توضیحات** - برای ورود توضیحات پروژه
3. **خدمات** - برای انتخاب خدمات مورد نیاز
4. **بودجه** - برای انتخاب محدوده بودجه
5. **تکمیل** - برای تکمیل ثبت فرم

پروژه به طور کامل واکنش‌گرا (Responsive) طراحی شده و در دستگاه‌های مختلف (موبایل، تبلت و دسکتاپ) به خوبی نمایش داده می‌شود.

# Multi-Step Form with RTL Support

## Introduction

This project is a multi-step form with full Right-to-Left (RTL) support for Persian language. It's built using React and TypeScript, and uses the Vazir font for displaying Persian text.

The multi-step form includes 5 steps:
1. **Your Name** - For entering name and email
2. **Description** - For entering project description
3. **Services** - For selecting required services
4. **Budget** - For selecting budget range
5. **Complete** - For completing the form submission

The project is fully responsive and displays well on different devices (mobile, tablet, and desktop).

## Features

- Right-to-Left (RTL) design for Persian language
- Using Vazir font
- Responsive design for all devices
- Easy navigation between different form steps
- Form validation
- Display of step completion status
- Beautiful and modern user interface

## Technologies Used

- React 18
- TypeScript
- Vite
- Pure CSS (no CSS frameworks)
- Vazir Font

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/vazir-multi-step-form.git
cd vazir-multi-step-form
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Building for Production

To build the application for production, run:

```bash
npm run build
# or
yarn build
```

The build files will be generated in the `dist` directory.
